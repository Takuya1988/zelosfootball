# ZELOS UNIFORM — オリジナルユニフォーム販売ページ

ユニフォーム販売用の3ページです。

**デザイン方針**：サイト本体はあえて無色（白背景・黒/グレー文字・モノクロ）で、シンプルかつかっこいいエディトリアル調にしています。イラストや装飾は使わず文字中心。色は、ユニフォームをつくる人が選ぶデザイン（＝後から載せるサンプル画像）から生まれる——「色を選ぶのはユニフォームをつくる人。その色が、私たちの色になる」というメッセージを表現しています。

## ファイル構成

```
uniform/
├── index.html     … ホーム（案内・価格・条件・素材・注文の流れ）
├── samples.html   … デザインサンプル（テンプレートとして選択可能）
└── contact.html   … お問い合わせ（メール／フォーム）
```

## GitHub（Takuya1988/zelosfootball）への設置方法

1. この `uniform` フォルダごとリポジトリのルートに追加してプッシュ
2. Vercel で自動デプロイされ、`https://svzfc.com/uniform/` で公開されます
   - 単独ドメインにしたい場合は、このフォルダを別リポジトリにしてもそのまま動きます（各ページは相対リンクのみ使用）

## 公開前に必ず差し替えるもの

### ① お問い合わせ用メールアドレス（`contact.html`）

`t.watanabe@svzfc.com` に**設定済み**です。変更する場合のみ、`contact.html` 内の
`t.watanabe@svzfc.com`（表示リンクと JavaScript の `CONTACT_EMAIL`）を書き換えてください。

### ② デザインサンプルの編集・画像追加（`samples.html`）

サンプルは各カードに**画像スペースを確保**しています。画像がまだない時は、番号入りの
グレーのプレースホルダー枠が表示されます。

- **画像を載せる**：`SAMPLES` 配列の各項目の `img` に画像ファイルのパスを指定します。
  例：`{name:"SIMPLE LINE", jp:"...", desc:"...", img:"img/sample-01.png"}`
  画像は `uniform/img/` フォルダに入れてください（`sample-01.png` のように連番がおすすめ）。
- **背景は白で統一**：黒背景のモックアップ画像は、背景だけを白に置き換えて掲載しています
  （ユニフォーム内部の黒い襟・番号・ラインは保持）。新しい画像も同様に白背景へ統一します。
- **拡大表示**：画像付きカードはクリックでライトボックス拡大表示されます（クリック／Escで閉じる）。
- **画像なしに戻す**：`img:""` にするとプレースホルダー枠に戻ります。
- **縦横比の変更**：CSS の `.thumb` 内 `aspect-ratio:3/2` を変更（例：`1/1` で正方形）。
- **追加・削除・並び替え**：`SAMPLES` 配列を編集するだけ。No. と件数は自動更新されます。
